# 基于 ADB 的视频自动截图程序 —— 实现方案

> 对应 idea：`doc/idea/202611092220_基于ADB的视频自动截图程序.md`
> 目标：把旋风战车队视频按片段截图 + 双语字幕拼成可打印画册
> 日期：2026-11-09

## 0. 已验证的事实（前期探索结论）

| 事实 | 值 |
|---|---|
| 模拟器 | 雷电 LDPlayer，`E:\leidian\LDPlayer14`，adb 序列号 `emulator-5554`，root 可用 |
| App | 小小优趣 `com.ukids.client.phone`，分辨率 1920×1080 |
| 缓存视频 | `/sdcard/Android/data/com.ukids.client.phone/files/ukids/vod/<vid>_0/*.ts`，AES-PRIVATE 加密，**解密路线已放弃** |

**核心决策**：视频源用「模拟器后台播放 + ADB 录屏」，字幕优先用 SRT 文本渲染（录制画面底部虽有字幕，但 SRT 文本更干净、排版可控）；画面带裁剪作为无 SRT 时的兜底。

## 1. 总体数据流

```
┌─ 模拟器(小小优趣播放) ─────────────────┐
│                                        │
│  adb: screenrecord 链式录制(≤180s/段)  │← 段启动时记录设备时间戳
└──────────────┬─────────────────────────┘
               │ adb pull seg_XXX.mp4
               ▼
┌─ 本地处理 ──────────────────────────────┐
│ 1. concat 分段 mp4 → full.mp4           │
│ 2. 场景/关键帧切分 → 片段列表[t0,t1]     │
│ 3. 每段取中点帧 → key.png               │
│ 4. SRT 解析 → 每段对应的台词(中/英)      │
└──────────────┬─────────────────────────┘
               ▼
┌─ 合成输出 ──────────────────────────────┐
│ 长图: 帧 + 台词 纵向拼接 → book_XXX.png │
│ 画册: A4 分页 PDF → book_XXX.pdf        │
└─────────────────────────────────────────┘
```

## 2. 模块设计

```
ukids_book/
  adb.py        # AdbDevice：定位 adb、设备选择、shell/pull/tap/screencap（吸收 screenshot.py）
  capture.py    # Recorder：链式 screenrecord、段时间戳、自动停止（时长来自 m3u8/db）
  subtitles.py  # SrtParser：BOM/双语解析、按时间段查询；SubtitleBand 图像带兜底(ahash 去重)
  segment.py    # ffmpeg：场景切分(select=scene)/关键帧/GOP 三种模式，中点抽帧
  compose.py    # 长图合成、字幕渲染(Pillow + msyh.ttc)、A4 分页 PDF
  pipeline.py   # 串联全流程
  cli.py        # 命令行入口
```

### 2.1 adb.py —— 设备层
- 自动定位 adb（PATH → 雷电目录列表，含 `E:\leidian\LDPlayer14`）
- 设备选择：优先 `emulator-*`，`127.0.0.1:5555` 与 `emulator-5554` 去重（已踩过的坑）
- 封装：`shell()`、`pull()`、`tap(x,y)`、`screenshot()`（保留原 screenshot.py 能力作为轻量模式）
- **注意**：外部调用需 `MSYS_NO_PATHCONV=1`，或全部经由 Python `subprocess`（列表参数，不经 shell），路径写 `/sdcard/...` 不受 Git Bash 转换影响 → 推荐 Python 内直接 subprocess，无此坑

### 2.2 capture.py —— 录制
- 链式 `screenrecord --bit-rate 12M --size 1920x1080 --time-limit 175 /sdcard/ukcap/seg_NNN.mp4`
  - 用 175s 留出重启余量；段启动时记录 `设备时间戳`（`adb shell date +%s.%N`）用于时间轴映射
- 停止条件：达到目标时长（单集 1265s + 10s 余量）或用户 Ctrl+C（SIGINT 后 pull 已完成段）
- 结束后批量 `pull` 到本地 `work/<vid>/raw/`
- 备选模式 `--mode shot`：定时 screencap（每 N 秒一张），适合只要关键帧不要连续流的快用场景

### 2.3 时间轴映射（关键设计）
- 段 i 内本地时刻 t → 视频时刻：`video_t = (wall_start_i + t) - wall_t0`
- `wall_t0`：脚本起录后立即 `tap` 播放键的设备时刻（流程：用户暂停在片头 → 启动脚本 → 脚本起录+点播放）
- 误差来源：起播延迟、段间空隙（~0.5-1s 丢帧，画册可接受）
- 提供 `--offset` 手动微调；SRT 匹配容差 ±1.5s（台词取该片段时间范围内所有 cue）

### 2.4 segment.py —— 分片与抽帧
- 三种模式（`--seg-mode`）：
  - `scene`（默认）：`ffmpeg -i full.mp4 -vf "select='gt(scene,0.3)',showinfo"` 取场景突变时刻为切点，叠加最小段长 8s / 最大 20s 约束（避免碎片段，保证一页一个"情节"）
  - `gop`：`ffprobe -skip_frame nokey` 取关键帧时刻切分（字面意义的"按关键帧切开"）
  - `fixed`：固定间隔 N 秒
- 每段取**中点帧**：`ffmpeg -ss <mid> -i full.mp4 -frames:v 1 key_NNN.png`
- 关键帧默认裁掉底部字幕带（y≈920-1080，占 15%），避免与下方渲染的 SRT 台词重复；`--keep-band` 可保留

### 2.5 subtitles.py —— 字幕
- SRT 解析：去 BOM、`-->` 时间解析、cue 内两行（中文/英文）拆分
- 查询接口：`cues_in(t0, t1, tol=1.5)` 返回片段内台词序列
- **兜底（无 SRT 的流媒体视频）**：片段内每 0.5s 抽帧，裁底部字幕带，平均哈希去重相邻重复，按序拼接为图像条（不 OCR，保留原样式）
- SRT 与视频的配对：v1 用 CLI 参数 `--srt <path>` 手动指定；后续可按下载时间自动配对

### 2.6 compose.py —— 合成输出
- 长图布局（宽 1200px，段间距 40px，白底）：

```
┌──────────────────────────┐
│   关键帧（中点） 1200×675  │  ← 已裁字幕带
├──────────────────────────┤
│ 中文台词（微软雅黑 34px）   │
│ English line (28px)      │
│ [多台词时逐条向下排]       │
└──────────────────────────┘
        ↕ 40px 间隔
```

- 画册模式（`--book`）：A4 竖版 300dpi（2480×3508），每页 2 段，页边距 15mm，输出 PDF（Pillow `save(all)`）
- 字体：`C:\Windows\Fonts\msyh.ttc`（微软雅黑），缺字体时回退 PIL 默认并警告

## 3. CLI 设计

```bash
# 全流程：起录 + 点播放 → 录完自动处理出长图
python -m ukids_book.cli record --vid E315 --duration 1275 --srt path/to/xxx.srt

# 只处理已录好的 mp4
python -m ukids_book.cli build --vid E315 --video work/E315/full.mp4 --srt xxx.srt --book

# 轻量模式：定时截图（不要连续流）
python -m ukids_book.cli record --mode shot --interval 10

# 微调
python -m ukids_book.cli build ... --seg-mode scene --scene-th 0.3 --min-sec 8 --offset 0
```

- **conda 环境 `py313_adb_auto`**（Python 3.13 + Pillow，已创建）

- 无需安装安卓端任何东西；不需要 root（录屏、pull 公共目录均可；拉 SRT 需要读 `/sdcard/Android/data/...` —— 雷电 9 的 Android 9 无 Scoped Storage 限制，实测可直接读）

```
项目/
├── doc/                 # 文档：idea/ 原始想法，plan/ 实现方案
├── ukids_book/          # 主源码包（adb/capture/subtitles/segment/compose/pipeline/cli + config）
├── scripts/             # 独立小工具（screenshot.py，输出到 work/screenshots/）
```

所有外部路径（adb、ffmpeg、字体、设备目录）统一收口在 `ukids_book/config.py`。

## 5. 风险与对策

| 风险 | 影响 | 对策 |
|---|---|---|
| screenrecord 180s 上限 | 段间丢帧 0.5-1s | 画册场景可容忍；字幕走 SRT 不受影响；不满足再升级 scrcpy（无限制、纯 adb 协议） |
| 时间轴误差累积 | 字幕错位 | 段启动时间戳映射 + `--offset` 手调；±1.5s 容差 |
| 场景切分阈值不稳 | 段落过碎/过长 | min/max 段长钳制；三种模式可切换 |
| 无 SRT 的视频 | 字幕缺失 | 图像带裁剪兜底（ahash 去重） |
| 模拟器掉帧 | 演唱/快闪场景糊 | `--bit-rate` 可调；1080p 12Mbps 起步 |
| SRT 配对错视频 | 字幕完全对不上 | v1 手动指定；错误一眼可见（台词与画面不符） |

## 6. 实施计划

| 阶段 | 内容 | 验收标准 |
|---|---|---|
| P0 最小闭环 | adb.py + capture.py + segment.py(scene) + subtitles.py(SRT) + 长图合成，跑通一集 | 一集 E315 产出 book.png：段落数 60~160，每段有帧有双语台词，肉眼可读 |
| P1 质量调优 | 场景阈值/段长参数化、关键帧避开转场帧、字幕排版（多台词折行、页距） | 连续 3 集产出稳定，无空段/无错位台词 |
| P2 画册输出 | A4 PDF 分页、封面（集数+标题，来自 Player_Download.db）、批量模式 | 直接可打印的 PDF，页码/标题齐全 |
| P3 可选增强 | scrcpy 无缝录制、UI 自动化自动连播下一集、无 SRT 图像带兜底 | 无人值守连续处理多集 |
