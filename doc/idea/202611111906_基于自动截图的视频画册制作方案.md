# 背景
1. 需要人为去判断哪一张图片作为每页的主图合适，自动识别的不一定合适
2. 基于字幕文件的方式会受限于播放软件的实现，或者字幕文件的格式，不同的不一定合适
3. 基于上述原因，需要实现半自动的视频自动截图成册工具，初步思路如下，之前的方式摒弃


# 初步思路
1. 第一步：x 秒截图一次，每次启动的时候，就截图到文件夹中，文件名的形式是 YYMMDDHHmmss.png
2. 第二步：扫描本次的文件夹，使用图片识别算法，来判断是否切镜头，按照切镜头来生成序列，序列的每一步都有一个主图，和本镜头的其他图片列表，其中，主图默认是序列的中间一帧，生成一个 yaml 文件表达这个序列
3. 第三步：使用图片拼接算法，把每一序列的主图+字幕区图片 拼接成长图，并生成 PDF, PDF 还有页码
